<h2 id="-sobre-mí-versión-en-español">🇪🇸 Sobre Mí</h2>

Desarrollador de Software especializado en **desarrollo Full-Stack**, **automatización de procesos de negocio**, **integraciones con Inteligencia Artificial (LLMs, RAG)** y **análisis de datos / plataformas de Business Intelligence a medida**.

Apasionado por transformar flujos de trabajo manuales en arquitecturas automatizadas, inteligentes y eficientes, combinando interfaces modernas con motores de datos robustos.

### 🚀 ¿En qué me enfoco?
- 🤖 **Automatización Empresarial & Agentes IA:** Creación de workflows avanzados en **n8n** y **Flowise**, integración con APIs de IA (OpenAI, Claude, modelos locales) e implementación de arquitecturas **RAG (Retrieval-Augmented Generation)** con bases de datos vectoriales.
- 💻 **Desarrollo Web Full-Stack:** Creación de aplicaciones escalables y performantes con **Next.js**, **React**, **TypeScript**, **Python** y **SQL**.
- 📊 **Data Analytics & Plataformas BI Web:** Desarrollo de dashboards interactivos tipo BI construidos a medida en **HTML, CSS y JavaScript (YJS)**, pipelines de **ETL**, extracción, limpieza y modelado de datos para toma de decisiones ejecutivas.
